# PyPr_8

**Обучение Skypro, самостоятельная практика по  разделу 12.2 Библиотека logging**

# структуру модулей:

- *src/api_client.py* — отвечает за запрос к API hh.ru.

- *src/vacancy_filter.py* — отвечает за фильтрацию вакансий по словам (включая/исключая).

- *src/file_saver.py* — отвечает за сохранение данных в JSON-файл.

- *src/main.py* — главный модуль, который связывает всё вместе.
