# PyPr_9: Парсер удаленных вакансий с Himalayas API

## 🎯 Назначение проекта

Этот проект представляет собой консольное приложение на Python, которое автоматизирует процесс поиска удаленной работы. Вместо ручного просмотра сайтов, скрипт самостоятельно собирает свежие вакансии, фильтрует их по заданным критериям и сохраняет результат в удобный JSON-файл.

Проект решает три главные задачи:
1. **Автоматизация сбора данных:** Мгновенно получает актуальный список вакансий через открытое API сервиса Himalayas.
2. **Умная фильтрация:** Позволяет отсеять вакансии, которые вам не подходят, по ключевым словам (например, убрать руководящие должности).
3. **Структурирование информации:** Сохраняет только самое важное (название, зарплатную вилку, валюту и ссылку) в чистый JSON-файл.

## 🏗 Архитектура проекта

Проект построен по модульному принципу (разделен на файлы в папке `src/`), чтобы код было легко читать и поддерживать:

* **`api_client.py`** — «Связной». Отвечает за запрос к API Himalayas, обрабатывает сетевые ошибки и таймауты.
* **`vacancy_filter.py`** — «Фильтр». Берет сырые данные, вытаскивает нужные поля (зарплату, валюту, ссылку) и применяет стоп-слова.
* **`file_saver.py`** — «Архивариус». Сохраняет итоговый список в файл с уникальным именем (дата + поисковый запрос).
* **`main.py`** — «Дирижер». Настраивает логирование и связывает все модули в единую цепочку.

## 💡 Примеры использования и замена ключевых слов

Главная «фишка» проекта — гибкость настройки поиска. Все параметры вы задаете в файле `src/main.py` в функции `main()`.

### Пример 1: Поиск Python-разработчика (Базовый)
Допустим, вы ищете разработчика на Python, но не хотите видеть руководящие должности.

**Что меняем в `main.py`:**
```python
``` 
```
search_word = "python"
stop_words = ["senior", "lead", "manager"]
```

Результат: Скрипт найдет вакансии с упоминанием Python, но выбросит из списка 
«Senior Python Developer» и «Python Team Lead». В итоге вы получите файл 2026-11-23_python.json.


### Пример 2: Поиск аналитика данных
Вы хотите попробовать себя в аналитике, но вас не интересуют стажировки.

**Что меняем в `main.py`:**

``` 
search_word = "data analyst"
stop_words = ["intern", "junior", "trainee"]
```

### Результат: 

Программа сделает запрос к API, найдет все вакансии аналитиков, но удалит из них предложения для новичков. 
Файл будет называться 2026-11-23_data_analyst.json.

### Пример 3: Поиск на русском языке
Himalayas — международный сервис, но там есть вакансии, где требуют русский язык.

**Что меняем в `main.py`:**

```
search_word = "russian"
stop_words = ["sales", "support"]
```

### Результат: 

Вы получите список вакансий, где требуется знание русского, исключив при этом продажи и поддержку. 
Имя файла будет 2026-11-23_russian.json.

### 🛠 Технологический стек

Язык: Python 3.13

Библиотеки: requests (для HTTP-запросов), python-dotenv (для конфигурации).

Инструменты: Poetry (управление зависимостями), Flake8/Black (чистота кода), 
стандартная библиотека logging (для отладки).


### 🚀 Как запустить

1.Убедитесь, что у вас установлен Python 3.13 и Poetry.

2.Клонируйте репозиторий и перейдите в папку проекта.

3.Установите зависимости:

```
poetry install
```

4.Настройте файл .env (пример в .env.example).

5.Запустите главный модуль:

```
python src/main.py
```
